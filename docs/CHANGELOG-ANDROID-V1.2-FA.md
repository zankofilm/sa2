# مدرسه‌یار — اندروید V1.2: بازطراحی داشبورد دخترانه

## علت نسخه جدید
نسخه V1.1 فقط پنل وب موجود را داخل WebView نمایش می‌داد؛ به طرح انتخاب‌شده یاسی/صورتی شباهت کافی نداشت و یک نوار ابزار اضافی بالای صفحه دیده می‌شد.

## اصلاحات V1.2
- حذف نوار ابزار تکراری اندروید و باقی‌ماندن تنها هدر خود پنل
- صفحه اصلی دخترانه یاسی/صورتی با تصویر خوشامدگویی مورد تأیید، ۸ کاشی ناوبری، آیکون‌های یکدست، بخش «کارهای امروز»، «پیگیری‌های مهم»، وضعیت آفلاین و همگام‌سازی
- شمارنده‌های تکالیف، آزمون، کلاس و اعلان از DOM تولیدشده توسط پنل اصلی خوانده می‌شوند؛ عدد آزمایشی و نمره جعلی وارد نمی‌شود
- نوار پایین خانه/آزمون‌ها/تکالیف/پیام‌ها/بیشتر با آیکون‌های برداری
- دکمه چت به سیستم واقعی p58 و اعلان داخل برنامه به دکمه واقعی اعلان‌ها وصل است
- دکمه به‌روزرسانی همان قابلیت همگام‌سازی سرور پنل اصلی را اجرا می‌کند؛ در حالت آفلاین خطا نشان می‌دهد و داده‌های قدیمی را پاک نمی‌کند
- تمام بخش‌های اصلی پنل وب، ورود، ذخیره داده، ارسال پاسخ، کارنامه، آزمون‌ها، فایل‌ها و مجوزها همان کد قبلی‌اند و دستکاری نشده‌اند.

## محدودیت‌ها و مسائل باقی‌مانده
- این نسخه بازطراحی **صفحه خانه** و نوار ناوبری و ظاهر پایه اپ است؛ محتوای زیرصفحه‌های تخصصی هنوز عمدتاً همان رابط وب و عملکردهای واقعی آن‌ها هستند و برای طراحی پیکسل‌به‌پیکسل همه ماژول‌ها باید جداگانه UI هر صفحه پیاده‌سازی شود.
- پوسته جدید فقط در APK فعال است؛ ظاهر وب‌سایت روی مرورگر تغییر نمی‌کند.
- ساخت نهایی APK و عملکرد روی گوشی باید در GitHub Actions/دستگاه تأیید شوند؛ Android SDK روی محیط توسعه این بسته موجود نبود.
- اعلان واقعی گوشی هنگام بسته بودن اپ بدون `google-services.json`، Firebase و فعال‌سازی امن سرور کار نمی‌کند. از بسته Push قبلی بدون بررسی سازگاری با آخرین سرور استفاده نکنید.
- همگام‌سازی آفلاین تابع پشتیبانی واقعی هر ماژول وب است؛ ارسال قطعی نیازمند اینترنت و رسید سرور است.

## ساخت در GitHub
پوشه‌های `app/`, `.github/`, `tests/` و فایل‌های Gradle را در ریشه مخزن private بگذارید. از Actions > Build Android APK استفاده کنید. APK قبلی V1.1 باید با APK جدید V1.2 جایگزین شود. بسته `server-integration` فقط برای توسعه آینده و نصب‌نکردن مستقیم روی سرور همراه پروژه مانده است.

## آزمایش پس از نصب
1. صفحه خانه یاسی/صورتی و کاشی‌ها/نوار پایین؛ **نباید نوار ابزار دوگانه دیده شود**.
2. تعداد تکالیف و آزمون را با پنل وب مقایسه کنید.
3. کارت کارنامه و چت معلم را جدا باز کنید.
4. پیام‌های خوانده‌نشده و اعلان داخل برنامه را بررسی کنید.
5. دکمه به‌روزرسانی در اینترنت متصل و قطع را تست کنید.
6. ورود/خروج و فرستادن فایل/پاسخ آزمون را صرفاً با حساب آزمایشی تست کنید.
7. پس از تنظیم Firebase و افزونه سرور، اعلان Push بسته‌بودن اپ را جداگانه تست کنید.
