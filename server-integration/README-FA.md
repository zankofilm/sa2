# اتصال سرور مدرسه‌یار به اعلان گوشی (FCM)

**این مرحله برای ساخت APK ضروری نیست.** اگر APK بدون این مرحله ساخته شود، پنل دانش‌آموز و چتِ آنلاینِ موجود قابل استفاده‌اند ولی اعلان Push وقتی برنامه بسته است **فعال نیست**.

## فایل‌های تغییرکرده

این بسته یک overlay برای **سورس تأییدشده P67.19.5** است. فایل‌های زیر را فقط پس از تطبیق با نسخه واقعاً نصب‌شده و گرفتن نسخه پشتیبان به پوشه ریشه Node.js مدرسه انتقال دهید:

- `INSTALL-ROOT/server.mjs`: اضافه شدن ثبت/لغو توکن، ارسال Push بعد از پیام معلم، انتشار آزمون رسمی، انتشار تکلیف و اطلاعیه
- `INSTALL-ROOT/student/app.js`: لغو بهترین‌تلاشی توکن همین دستگاه هنگام خروج دانش‌آموز
- `INSTALL-ROOT/shared/mobile-push.mjs`: مخزن خصوصی دستگاه‌ها، اعتبارسنجی نشست، ارسال FCM
- `INSTALL-ROOT/package.json`: بسته `firebase-admin`

**هرگز** پوشه `data`، `security.json`، `state.json`، داده‌های دانش‌آموزان، رمزها، گواهی‌های Firebase یا نسخه‌های پشتیبان را در GitHub قرار ندهید یا از فایل ZIP روی هاست جایگزین نکنید.

## راه‌اندازی Push واقعی

1. در Firebase Console یک پروژه و Android app بسازید؛ Package name دقیق: `ir.madreseyar.student`.
2. فایل `google-services.json` را فقط برای build اندروید در GitHub Actions به شکل secret ذخیره کنید؛ به سرور عمومی ندهید.
3. در Firebase Console از بخش IAM/Service Accounts، کلید Admin SDK مخصوص سرور را دریافت و خارج از `public_html` و GitHub ذخیره کنید.
4. مسیر فایل Admin SDK را فقط در متغیر محیطی سرور Node.js تعریف کنید: `GOOGLE_APPLICATION_CREDENTIALS=/private/path/firebase-service-account.json`.
5. متغیر محیطی `MADRESEYAR_FCM_ENABLED=1` را تنظیم کنید.
6. در پوشه نصب سرور `npm install --omit=dev` اجرا کنید و Node.js را ری‌استارت کنید.
7. روی APK وارد یک حساب دانش‌آموز آزمایشی شوید، مجوز اعلان بدهید و از حساب معلم مرتبط، پیام واقعی بفرستید. اگر اعلان رسید، با لمس آن باید به چت باز شود.

## امنیت و دامنه اجرا

- هویت دانش‌آموز از Bearer token معتبر خوانده می‌شود و سرور خود شناسه دانش‌آموز را تعیین می‌کند. هیچ کاربر دیگری نمی‌تواند توکن دستگاه را برای حساب دلخواه ثبت کند.
- هنگام ارسال اعلان، فقط دستگاه‌هایی انتخاب می‌شوند که نشست دانش‌آموزی معتبر و منقضی‌نشده دارند. نشست لغوشده، حتی اگر دستگاه آفلاین از برنامه خارج شده باشد، پیام Push جدید نمی‌گیرد.
- شناسه دستگاه و توکن FCM در `data/push-devices.json` با سطح دسترسی خصوصی ذخیره می‌شوند. هیچ محتوای نمره یا متن گفتگوی شخصی داخل اعلان صفحه قفل فرستاده نمی‌شود.
- در خروج عادی، بهترین تلاش برای لغو توکن انجام می‌شود؛ اگر کاربر هنگام قطع اینترنت خارج شود، لغو فوری سروری ممکن نیست و اعلان‌های عمومی ممکن است تا لغو یا انقضای نشست معتبر قبلی ادامه داشته باشند؛ قبل از استفاده روی گوشی مشترک باید این سناریو به‌صورت عملی برطرف و تست شود.
- این اتصال برای Push پیام معلم به دانش‌آموز، تکلیف انتشار یافته، آزمون رسمی منتشر شده از مسیر P67.6 و ارسال اطلاعیه مستقیم پیاده‌سازی شده. تمام رویدادهای برنامه مثل تغییر برنامه، نمره، نتایج، اعتراض و یادآورهای زمان‌بندی هنوز پوشش Push ندارند و به توسعه جداگانه نیاز دارند.
- پوشش کامل نسخه وب در WebView است؛ برای پیام‌رسانی **همان API `p58`** استفاده شده، پیام‌ها جدا ذخیره نمی‌شوند.

## هشدار استقرار

سرور تولیدی یک سامانه حساس آموزشی است. این `server.mjs` دقیقاً بر پایه P67.19.5 آماده شده؛ اگر از آن زمان فایل سرور تغییر کرده، **نباید آن را کورکورانه جایگزین کنید**. ابتدا تغییرات را Merge و در محیط آزمایشی امتحان کنید. برای build APK نیازی به نصب این overlay نیست.
