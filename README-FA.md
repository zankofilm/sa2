# نسخه V1.2 — داشبورد دخترانه مطابق طرح منتخب

**تغییر جدید:** نسخه قبلی صرفاً WebView پنل وب را نشان می‌داد و با طرح انتخابی هماهنگ نبود. در V1.2 صفحه خانه و نوار پایین APK با تم یاسی/صورتی و کارت‌های واقعی از پنل بازطراحی شده‌اند؛ نوار بالایی اضافی حذف شده است. سایر زیرصفحه‌ها همچنان از منطق و رابط اصلی وب استفاده می‌کنند. برای توضیحات دقیق، `docs/CHANGELOG-ANDROID-V1.2-FA.md` را بخوانید.

**نصب روی سایت لازم نیست:** این پچ تغییر ظاهری داخل APK است؛ کد سرور و بانک اطلاعاتی مدرسه را جایگزین نکنید. برای ساخت، فایل‌های همین پروژه را در مخزن GitHub قبلی آپدیت و Actions را اجرا کنید. فعال‌سازی Push واقعی هنوز به Firebase و اتصال امن سرور نیاز دارد.

# مدرسه‌یار | اپلیکیشن اندروید پنل دانش‌آموز

پروژه قابل ساخت در **GitHub Actions** و **Android Studio**، شامل آیکون رسمی منتخب (کتاب باز یاسی/صورتی)، پوسته اندروید، کل پنل وب فعلی دانش‌آموز، چت واقعی p58، همگام‌سازی موجود و کد اعلان Push با Firebase Cloud Messaging.

## دقیقا چه چیزی کار می‌کند؟

- ✅ پیکربندی پروژه و گردش‌کار ساخت APK Debug در GitHub (تأیید نهایی کامپایل در اجرای Actions انجام می‌شود)
- ✅ نمایش **تمام ماژول‌های موجود پنل وب دانش‌آموز** از آدرس رسمی HTTPS مدرسه: ورود، داشبورد، آزمون، تکلیف، کارنامه، کتابخانه، تمرین، چت، برنامه، پروفایل و ... . این برنامه «WebView امنِ پنل موجود» است، نه بازنویسی همه ۲۸ ماژول به Kotlin/Java.
- ✅ دکمه همگام‌سازی که دکمه واقعی «به‌روزرسانی» پنل وب را می‌زند، بدون پاک‌کردن داده‌های محلی
- ✅ دکمه چت معلم که به سیستم پیام‌رسانی موجود p58 وصل می‌شود (ارسال پیام **فقط آنلاین**)
- ✅ امکان فایل‌گزینی برای پاسخ‌ها و دانلودهای HTTPS از سایت رسمی
- ✅ حافظه آفلاین وب از طریق IndexedDB و Service Worker همان پنل، به میزان پشتیبانی فعلی ماژول‌ها؛ همه فایل‌ها و زیرصفحه‌ها الزاماً آفلاین نیستند
- ✅ کد FCM برای اعلان گوشی در حالت بسته / پس‌زمینه، با مجوز Android 13+، کانال اعلان و مقصد داخل اپ؛ **فقط پس از تنظیم Firebase و نصب افزونه سرور فعال می‌شود**.

## ۱ — ساخت APK در GitHub بدون نیاز به کامپیوتر قوی

1. وارد github.com شوید؛ مخزن **Private** جدید مثلاً `madreseyar-student-android` بسازید.
2. ZIP سورس را روی دستگاه استخراج کنید. **فایل‌های داخل پوشه** `Madreseyar-Student-Android-GitHub` را در ریشه مخزن آپلود کنید (خود ZIP را به‌عنوان تنها فایل آپلود نکنید). مخزن نباید عمومی شود، چون کد اتصال مدرسه در آن است.
3. به تب **Actions** بروید؛ workflow با نام `Build Android APK` را انتخاب و `Run workflow` بزنید. اگر Actions غیرفعال بود آن را در تنظیمات مخزن فعال کنید.
4. پس از موفق شدن اجرا، در قسمت **Artifacts** فایل `Madreseyar-Student-Debug-APK` را بگیرید، استخراج کنید و `app-debug.apk` را روی اندروید نصب کنید.
5. روی گوشی «اجازه نصب از این منبع» را هنگام نصب بدهید (در صورت نیاز).

> این APK از نوع Debug است و برای آزمایش مناسب است، **نه انتشار عمومی**. برای نسخه نهایی باید keystore امن، امضای Release، سیاست حریم خصوصی و تست واقعی داشته باشیم.

## ۲ — فعال‌سازی اعلان واقعی وقتی اپ بسته است

بدون Firebase فایل APK ساخته می‌شود، **ولی اعلان Push واقعی فعال نیست**. برای فعال‌سازی:

1. پروژه‌ای در `console.firebase.google.com` بسازید. Android app با package name دقیق `ir.madreseyar.student` ثبت کنید.
2. فایل `google-services.json` را دریافت کنید. محتوای همین فایل را به صورت Base64 تبدیل کنید و در GitHub → Settings → Secrets and variables → Actions → New repository secret با نام **`FIREBASE_GOOGLE_SERVICES_JSON_BASE64`** ذخیره کنید. کلید Service Account را اینجا قرار ندهید.
3. دوباره workflow را اجرا کنید تا APK با شناسه Firebase ساخته شود.
4. در سرور مدرسه فایل‌های `server-integration/INSTALL-ROOT` را فقط پس از بکاپ و تطبیق نسخه روی هاست نصب کنید؛ راهنمای `server-integration/README-FA.md` را بخوانید.
5. کلید **Firebase Admin SDK service account** را تنها در مسیر خصوصی سرور نگه دارید و متغیرهای `GOOGLE_APPLICATION_CREDENTIALS` و `MADRESEYAR_FCM_ENABLED=1` را در Node.js تنظیم کنید.
6. از یک حساب آزمایشی دانش‌آموز در APK وارد شوید و مجوز اعلان را تأیید کنید. سپس با معلم همان درس پیام ارسال کنید؛ به‌محض انتشار، سرور با FCM به گوشی می‌فرستد.

**مهم:** این مجموعه بدون فایل‌های محرمانه Firebase تحویل داده شده؛ ادعای «Push از همین حالا فعال است» درست نیست. برای دریافت Push به اینترنت گوشی نیاز است؛ پس از Force Stop اجباری برنامه توسط کاربر، اندروید ممکن است تا باز کردن مجدد برنامه اعلان‌ها را تحویل ندهد.

## ۳ — ساخت در Android Studio

پوشه مخزن را به عنوان Gradle Project باز کنید؛ JDK 17 و Android SDK API 35 لازم است. سپس `Build > Build APK(s)` یا `gradle :app:assembleDebug` را اجرا کنید. اگر می‌خواهید Push فعال باشد، فایل `google-services.json` را فقط در `app/` روی سیستم توسعه قرار دهید (در Git ignore شده).

## ۴ — امنیت داده‌ها و محدودیت‌ها

- اطلاعات واقعی مدرسه، اطلاعات دانش‌آموزان، دیتابیس، رمزها، توکن‌ها یا فایل `data/` در سورس Github **وجود ندارند**.
- اپ فقط آدرس HTTPS مدرسه‌یار را داخل WebView باز می‌کند. لینک‌های خارجی HTTPS در مرورگر خارجی باز می‌شوند و Schemeهای ناامن داخل وب‌ویو مسدودند.
- WebView همان سیاست ورود سایت را دارد. کش و پیش‌نویس‌ها در WebView نگهداری می‌شوند؛ **تمام ماژول‌ها آفلاین نیستند**، و ارسال قطعی آزمون/تکلیف/پیام به اینترنت و رسید سرور نیاز دارد.
- توکن حساب فعلاً از مکانیزم موجود وب یعنی localStorage گرفته می‌شود. اپ native مستقلاً رمز یا کد ملی را ذخیره نمی‌کند. برای گوشی اشتراکی/نسخه انتشار عمومی باید رمزگذاری/تفکیک کش هر دانش‌آموز و سیاست خروج کامل بررسی شود.
- در صورتی که آدرس رسمی `scooljavanrood.ir` تغییر کرد، باید هم در BuildConfig و هم در MainActivity whitelist دامنه را به‌طور هماهنگ تغییر دهید؛ هرگز اعتبارسنجی HTTPS/دامنه را حذف نکنید.
- API و پوستهٔ معلم، بانک‌های سؤال، نمره و داده‌های وب اصلی به‌صورت پیش‌فرض **هیچ تغییری نمی‌کنند**. پوشه `server-integration` اختیاری و **برای هاست** است؛ روی APK اثر مستقیم ندارد.

## ۵ — چک‌لیست تست پس از ساخت

ورود واقعی با دانش‌آموز آزمایشی؛ مشاهده تمام ۲۸ حوزه امکانات پنل وب؛ چت دوطرفه؛ باز شدن اعلان با لمس؛ ارسال فایل تکلیف؛ شروع و ارسال آزمون با رسید سرور؛ نمایش داده‌های دانلودشده بدون اینترنت؛ همگام‌سازی؛ حفظ کش در قطع اتصال؛ خروج/ورود با حساب متفاوت؛ Push هنگام باز بودن و بسته بودن اپ؛ مجوز اعلان Android 13+؛ بررسی مصرف باتری و تحویل اعلان با اینترنت ضعیف.

## ساختار مخزن

- `.github/workflows/android-apk.yml` — ساخت APK در GitHub Actions
- `app/` — پروژه کامل Native Android/WebView + FCM + آیکون
- `docs/app-icon-512.png` — تصویر ۵۱۲ پیکسلی آیکون انتخاب‌شده
- `server-integration/` — افزونه واقعی Push با احراز هویت روی همان سرور مدرسه‌یار
- `tests/` — آزمون‌های خودکار کد سرور Push

**وضعیت تست در این تحویل:** تست منطق ثبت دستگاه ۳/۳ موفق، آزمون نحوی سرور موفق، اجرای سرور در محیط ایزوله موفق (ping=200، ثبت Push بدون ورود=401، صفحه دانش‌آموز=200). در این محیط Android SDK/Gradle برای کامپایل نصب نبود؛ **هنوز نمی‌توان موفقیت ساخت APK یا کارکرد عملی Push را ادعا کرد**. اولین اجرای GitHub Actions و آزمون گوشی مرحله ضروری بعدی است.
